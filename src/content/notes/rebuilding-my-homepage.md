旧版主页上线已经有一阵子了。最近重新打开看了一眼，第一反应不是“还不错”，而是有点替当时的自己不好意思——首屏是一张 1.7 MB 的暗色粒子发光桌面图，右下角漂着一块毛玻璃状态窗，下面排着三列带彩色圆点的卡片，点进“能力页”甚至还有三条写着 `88%`、`82%`、`64%` 的渐变进度条。

那些元素单独看都不算错，合在一起却散发出一种非常熟悉的模板气息：像是在努力证明“我很酷、很会写前端、也很有幽默感”，但真正点开的人看了一圈，还是不知道我到底做过什么。

## 删掉空洞装饰，留住真实手感

重写过程中我踩过两个相反的坑：第一版太素，像一张没有生气的白纸；第二版又堆了太多英文小字和假仪表盘标签，反而像一套后台面板。最后才摸到舒服的平衡点——**版面要透亮、字要排得宽松，而每一处动效都应该服务于真实内容**：

- **首页直接放可玩的 `ScreenTranslate` 演示**：与其写三段形容词夸自己的工具好用，不如在页面里做一个能直接点选、拉出扫描线、弹出译文的轻量演示。
- **把克制留给背景与细节**：背景点阵会随着鼠标轻轻让开，页面切入带一点柔和的弹性，首屏放一只安静走动的实时表盘，不靠大段花哨标签抢戏。
- **删掉所有假内容**：原本硬撑出来的四个页面，现在收敛为首页、作品、随笔三部分，邮箱和 GitHub 随手可点。

> 好的个人主页不像产品发布会，更像一张整理过的书桌——东西不多、空间敞亮，而且摆在上面的每一样都是真的在用。

为了以后顺手记点笔记，这次把站点迁到了 Astro 5，用原生 Markdown 管理随笔。写一篇新文章只需要在 `src/content/notes/` 下新建文件：

```markdown
---
title: "一篇新随笔"
description: "简短说明这篇文章在聊什么。"
pubDate: 2026-11-24
tags: ["记录"]
---

从这里开始写正文。
```

推上 GitHub 之后，Actions 会自动完成构建并更新线上站点。不需要维护后台，也不用再和手动同步的静态 HTML 较劲。
